# Pedido del propietario: lo que toca a farmacia

Copiado literal del documento del propietario (Google Docs), pegado por Itzan el 2026-10-29. Solo las
partes que tocan a farmacia; el resto del documento no es de este carril.

## PACIENTE → «Conexión con farmacia»

> Cada receta médica tiene un QR escaneable que detalle cada ítem de la receta y esto le carga automático a
> la farmacia. En esto el usuario por sucursal marca si tiene o no dicho producto para que el usuario pueda
> reservar.
> El paciente desde la pestana Farmacia hace el pedido.
> Lo del QR se puede enviar directo desde Whatsapp o cualquier app de mensajeria. Vos lo abris con una
> camara normal y automatica te lleva a esa receta. Si vos tenes una sesion iniciada como farmacia la podes
> abrir perfectamente bien. NO ES UNA CARTA LIBRE PARA COMPRA PARA CUALQUIERA SINO PARA LA PERSONA
> ESPECIFICA PRESCRITA.
> Es necesario levantar un mockup server que simula una API de farmacia que simule a través de una
> estructura hexagonal el nexo de claves foráneas entre productos y su interpretación de cada cosa de modo
> que la información fluya entre ambos.
