# Contratos y dependencias — observados con alcance limitado

Este inventario es de lectura. Se revisaron referencias frontend y documentación/OpenAPI local del API; no se editaron repositorios API/modelo. Una integración aislada de registro profesional pasó 8/8 en una base desechable con semillas parciales, según REPORT.md; no equivale a init DDL canónica ni a un journey Médico completo API→DB→recarga. Un módulo o una tabla existente no prueba que el contrato satisfaga el proceso Médico.
