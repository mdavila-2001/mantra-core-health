Caché del PDP

El motor de decisión guarda en memoria lo que ya resolvió. Cuando cambiás un rol, un permiso o una política, hay que decirle que olvide lo viejo.

Invalidar la caché

No hay invalidaciones pendientes

Cada decisión que el motor resuelve queda cacheada unos minutos, para no recalcular lo mismo en cada clic. Después de cambiar un rol, un permiso o una política, invalidá la caché para que el cambio se note en el acto en lugar de esperar a que expire sola. Podés acotar la invalidación a una organización, a un usuario o a un rol.
