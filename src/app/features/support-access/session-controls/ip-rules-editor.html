¿Cómo se escribe una red? Ayuda en lenguaje simple
  • Una red se escribe con una dirección, una barra y un número: 190.129.0.0/16. El número dice cuántas direcciones abarca: cuanto más chico, más grande la red.
  • Una sola máquina termina en /32, por ejemplo 203.0.113.7/32. Sin la barra y el número, el rango no sirve.
  • Permitir: si hay alguna red permitida, solo se entra desde ellas. Bloquear: desde esa red no se entra nunca, aunque otra regla la permita.
  • Sin ninguna regla, no se restringe a nadie. Por eso encender «Red de la organización» antes de cargar la primera red no deja a nadie afuera.
  • Vigencia: si indica fechas, la regla rige solo entre esos días, ambos incluidos. Sirve para una visita o una obra de unos días.
  • Su proveedor de internet le puede decir qué rango usa su sede. Si su red cambia de dirección con frecuencia, pida una dirección fija antes de bloquear el resto.
