Catálogo completo de controles de entrada standalone con estado OnPush, tokens REDSAT y 12 variantes con sus estados (idle, focused, error, disabled).

1. Input de Texto (`text`)

2. Input de Correo (`email` con sanitización)

3. Input Numérico (`number` - Formato Tabular Nums)

4. Input de Contraseña (`password` - Toggle Ojo 1.6px)

5. Input de Búsqueda (`search` - Lupa + Botón Limpiar)

6. Input URL (`url` con sanitización)

7. Checkbox (`atoms/checkbox`)

8. Radio Button (`atoms/radio` + `atoms/radio-group`)
